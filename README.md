# Mathématiques et décisions de gestion — KEDGE EBP 1

Application statique « Aller plus loin » destinée à mobiliser les notions du cours dans des décisions de gestion.

## Contenu

- arbitrage budgétaire ;
- prévision de croissance ;
- comparaison de fournisseurs ;
- seuil de rentabilité ;
- analyse marginale ;
- optimisation ;
- cas intégrateur de lancement d'un produit.

Les calculs Python s'exécutent dans le navigateur avec Pyodide. Les graphiques utilisent Plotly. Aucune donnée n'est transmise.

## Déploiement GitHub Pages

Déposer le contenu du dossier `dist` à la racine du dépôt, puis activer GitHub Pages sur la branche `main` et le dossier racine.
